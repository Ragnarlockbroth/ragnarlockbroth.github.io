# Ben Buchler — final dark-navy portfolio

A static, mobile-friendly professional website with no build step or dependencies.

## Publish to GitHub Pages

**Recommended:** Create or rename a repository to `bbuchler27.github.io`. Upload the **contents of this ZIP** (all HTML files and the `assets/` and `downloads/` folders) into the repository root. Do not upload the ZIP itself and do not nest everything inside another folder. Under Settings → Pages, choose Deploy from a branch → `main` → `/ (root)` → Save. Your URL will be `https://bbuchler27.github.io/`.

**If you insist on a repository named `bbuchler27`:** Publish the same files from its root and use `https://bbuchler27.github.io/bbuchler27/`. The website uses relative links, so it works in either setup.
