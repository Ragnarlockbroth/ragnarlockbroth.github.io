# Ben Buchler — GitHub Pages Portfolio

An editable, multi-page static portfolio built with HTML, CSS, and JavaScript. No build tools or paid hosting required.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload the **contents** of this folder to the repository root. Do not upload only the ZIP file.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. After GitHub publishes the site, visit `https://YOUR-USERNAME.github.io`.

## Update your information
Edit `site-config.js` to add your email, LinkedIn, GitHub, location, degree, major, and expected graduation date.

## Edit pages
- `index.html`: bio and personal brand
- `skills.html`: technical and soft skills
- `projects.html` and `projects/`: project summaries and detail pages
- `experience.html`: work experience and accomplishments
- `education.html`: education and coursework
- `beyond.html`: leadership, philanthropy, skiing, and interests
- `assets/styles.css`: design and colors

Edit directly in GitHub with the pencil icon, or edit locally in VS Code and upload changes.
